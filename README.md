## 📜 Scripts

### 📥 [Gmail Label Organizer](./gmail-label-organizer/)

Automatically creates Gmail labels and **organizes your inbox by sender** into nested categories — Jobs, Finance, Dev, Shopping, and more.

- 🏷️ Auto-creates a clean, nested label taxonomy
- 🔁 **Resumable execution** — picks up where it left off on large inboxes (no timeouts)
- ⚡ **Auto-labeling triggers** keep new mail sorted going forward
- ↩️ **Undo support** to safely roll back changes

📖 Full setup & usage → [gmail-label-organizer/README.md](./gmail-label-organizer/README.md)

## 🚀 Quick Start

1. Open [script.google.com](https://script.google.com) → **New project**
2. Copy the `Code.gs` from the script's folder into the editor
3. Review the permissions it requests, then **Run** — that's it

> Everything runs inside *your* Google account. Nothing leaves Google's servers, and there's no third-party service in the loop.
